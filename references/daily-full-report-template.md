# Daily Full Report Template

Use this template for the long-form version of a daily paper scan.

## Recommended structure

```markdown
# YYYY-MM-DD Daily Full Report

## 1. Paper Title
- Authors: ...
- Published: ...
- ArXiv: ...
- PDF: ...
- Optional code: ...
- Novelty score (optional): X/5
- Relevance score (optional): X/5
- Key points:
  - ...
  - ...
  - ...
- Method highlight: ...
- Main limitation: ...

## 2. Paper Title
...
```

## Rules

- Full report should be denser than the brief.
- Explain method highlights and limitations, not just metadata.
- If using scores, define what they mean.
- Keep formatting consistent across papers.
