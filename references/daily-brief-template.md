# Daily Brief Template

Use this template for a short daily paper briefing.

## Goal
Help the reader quickly decide which papers are worth opening in full.

## Recommended structure

```markdown
# YYYY-MM-DD Paper Brief

## 1. Paper Title
- Link: arXiv / PDF / code
- One-line topic: ...
- Why it may matter: ...

## 2. Paper Title
- Link: ...
- One-line topic: ...
- Why it may matter: ...
```

## Rules

- Keep each paper short.
- Prefer 5 to 10 papers unless the user requests otherwise.
- Sort by relevance if a relevance score exists.
- Mention why each paper is worth reading, not just what it is.
